Première version d'**Atelier Instruments** : 3 instruments virtuels libres au son acoustique.

- **Atelier Piano** – piano à queue (Salamander Grand Piano, CC-BY 3.0)
- **Atelier Batterie** – batterie acoustique General MIDI avec mixeur par élément (Virtuosity Drums, CC0)
- **Atelier Cordes** – ensemble de cordes (VSCO 2 CE, CC0)

| Fichier | Pour |
|---|---|
| `AtelierInstruments-0.1.0-Windows-x64-Setup.exe` | Windows 10/11 64 bits – installateur (VST3) |
| `AtelierInstruments-0.1.0-Windows-x64-VST3.zip` | Windows – installation manuelle |
| `AtelierInstruments-0.1.0-macOS-universal.pkg` | macOS 10.13+ Intel & Apple Silicon – installateur (VST3 + AU) |
| `AtelierInstruments-0.1.0-macOS-universal-VST3-AU.zip` | macOS – installation manuelle |

Plugins **non signés** : sous macOS faites *clic droit → Ouvrir* sur le .pkg, ou `xattr -cr` sur les plugins (voir le LISEZMOI). Sous Windows, SmartScreen : *Informations complémentaires → Exécuter quand même*.
Code AGPLv3 (JUCE). Détails, installation dans FL Studio et limites : voir le README.
